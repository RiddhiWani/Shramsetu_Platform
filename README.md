# 🛠️ Shramsetu Platform
**An AI-driven ecosystem for labor management and hiring.**

Shramsetu is a specialized service platform built with Django to connect skilled laborers with employers. It features an intelligent AI Assistant for real-time support and a dynamic dashboard for profile management.

## 🚀 Features
* **Worker Dashboard:** A centralized hub to manage profile settings and skills.
* **Dynamic  Updates:** Users can update personal details.
* **Service Directory:** Categorized listings for hiring specific laborers like Plumbers or Electricians.

---

## 🤖 AI Assistant
* **Model:** Powered by Llama 3 via Groq API.
* **Function:** Provides real-time chat support for platform navigation and user queries.
* **Interface:** Integrated directly into the dashboard for easy access.

---

## 💻 Tech Stack
* **Framework:** Django (Python)
* **Database:** SQLite3 
* **Styling:** CSS3 & HTML5
* **Logic:** JavaScript (AJAX for Chat)

---

## 🛠️ Setup
1. **Clone:** `git clone https://github.com/yourusername/shramsetu.git`
2. **Install:** `pip install -r requirements.txt`
3. **Run:** `python manage.py migrate && python manage.py runserver`
